# Capitalio reference implementation

Source: [Capitalio by Watermelon](https://registry.watermelon.sh/r/capitalio-dashboard.json), re-fetched 16 November 2026. All twelve source files are retained **byte for byte** under `../watermelon/capitalio-dashboard/`. Their hashes are guarded by `tests/Design/test_capitalio_reference.py` and `docs/design-references/capitalio-source-manifest.json`.

| Upstream file                             | Use                                                                                                                                                                                                                            |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `components/capitalio/analytics-page.tsx` | Complete original preview Analytics: three-series performance, all three mini-chart cards, grouped period returns and stacked income. Native `native-analytics.tsx` retains all six frames without inventing missing measures. |
| `components/capitalio/dashboard-page.tsx` | Complete original preview Dashboard: four summaries, performance, allocation, holdings and smart insights. Native composition is split into `summary`, `native-charts`, `native-panels` and `native-dashboard`.                |
| `components/capitalio/icons.tsx`          | Original SVG geometry, used by preview and native sidebar, topbar, metallic badges and insight icons.                                                                                                                          |
| `components/capitalio/logo.tsx`           | Original preview logo. Native identity uses Kernscale name/initial inside the same source blue gradient badge.                                                                                                                 |
| `components/capitalio/navigation.tsx`     | Original preview route/period state, retaining all four periods. Native routes use Laravel/Inertia; actual windows use `native-data.ts`.                                                                                       |
| `components/capitalio/shared.tsx`         | Original preview card/header/tag/tooltip/marker. Native `shared.tsx` copies the same visual code without importing sample datasets.                                                                                            |
| `components/capitalio/sidebar.tsx`        | Complete original preview navigation/footer. Native `app-sidebar.tsx` retains its structure/effects, with actual authorized routes, user identity, truthful role badge and sign out.                                           |
| `components/capitalio/topbar.tsx`         | Complete original preview header. Native `topbar.tsx` retains date/range, all four periods and Export, with validated source dates and disabled export when unavailable.                                                       |

| `dashboard.css`                           | Used directly, unmodified, across the real app and preview. `capitalio.css` contains only primitive compatibility, straight action-arrow and reduced-motion adjustments.                                                       |
| `data.ts`                                 | Original full demonstration dataset, imported only by the local-owner design preview and its original vendor components. Never imported by native adapters.                                                                    |
| `demo.tsx`                                | Original entry wiring is preserved. `pages/hub/capitalio-preview.tsx` adapts its entry to Laravel, keeping complete original pages and adding a persistent sample-data marker, functional export and Full Analysis.            |

The preview is intentionally sample-only, with a persistent **Sample design data · Local owner preview** indicator. Its source data is not a paper-account snapshot. The backend restricts the route to an enrolled approved local owner. The real app uses only verified `native-paper-ledger` snapshots. Native risk limits are not a score, observed equity is not investment return, and missing classes/benchmarks/targets/tax/DRIP/income stay explicitly unavailable within the retained source frames.

The exact requested shadcn command completed. Every existing primitive was preserved at overwrite prompts. Generated duplicate output paths, duplicate mobile hook, unused CLI dependencies and pnpm lock were removed; npm's existing package lock remains canonical, with no new runtime dependency. The registry has no embedded license field/headers; this attribution and the full original source are retained. Existing shadcn and React Bits licenses are retained under `../hub/` (React Bits is MIT + Commons Clause).
