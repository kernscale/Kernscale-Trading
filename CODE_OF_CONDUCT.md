# Code of Conduct

Everyone participating in this project is expected to:

- Be respectful and constructive, including when disagreeing.
- Welcome questions and contributors with different experience levels.
- Discuss the work without harassment, discrimination, threats or personal attacks.
- Respect privacy, consent, attribution and other people's time.
- Avoid spam, impersonation and publishing another person's private information.

Maintainers may edit or remove inappropriate content, restrict participation or
ban contributors when necessary to protect the community. They will consider the
context and apply these expectations to their own conduct as well.

Report conduct concerns privately through a maintainer's published GitHub profile
contact channel. If no private channel is listed, an issue may request a private
contact channel without including names, allegations or sensitive details. For
security vulnerabilities, use [SECURITY.md](SECURITY.md).
